# CV Fillter Backend

Backend application for the CV Fillter project.

## Setup Remote Repository

Run these commands from this folder:

```bash
git branch -M main
git remote add origin <BACKEND_REMOTE_URL>
git push -u origin main
```

## Notes

- Replace `<BACKEND_REMOTE_URL>` with your backend repository URL.
- Example URL format: `https://github.com/your-username/cv-fillter-backend.git`
